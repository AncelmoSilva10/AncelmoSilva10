### 📖 Sobre Mim
🎓 Técnico em **Desenvolvimento de Sistemas** pela Etec de Guaianazes e, atualmente, graduando em **Ciência da Computação na SPTECH**.

🚀 Com uma base prática que passa pelo suporte de TI até a engenharia de software, iniciei minha jornada focado na lógica de programação e estruturação de sistemas. 

💻 Hoje, meu foco é integrar o desenvolvimento backend com a inteligência de dados. Construo desde arquiteturas e APIs robustas até a modelagem de bancos de dados relacionais e a implementação de dashboards para visualização e gestão de informações.
